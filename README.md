# 🌐 Simulación de Red PyME en Cisco Packet Tracer

Simulación de red de área local orientada a PyME implementada en Cisco Packet Tracer, con enfoque en conectividad robusta, enrutamiento estático y servicios integrados.

## 🚀 Características del Proyecto
* **Enrutamiento IPv4:** Configuración de rutas estáticas entre routers para garantizar la comunicación entre subredes.
* **Infraestructura Inalámbrica:** Integración de Access Points (AP) para la conexión de dispositivos móviles o de oficina.
* **Dispositivos IoT:** Incorporación y monitoreo de elementos de Internet de las Cosas dentro de la topología.
* **Segmentación de Red:** Distribución de direcciones IP eficientes para diferentes áreas de trabajo.

## 🛠️ Tecnologías y Herramientas Utilizadas
* **Cisco Packet Tracer:** Software de simulación de redes.
* **Protocolos IPv4 / DHCP / Estáticos.**

## 📂 Contenido del Repositorio
* `red-tcp-ip-pyme.pkt`: Archivo principal del proyecto listo para abrir y ejecutar en Cisco Packet Tracer.
